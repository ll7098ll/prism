# 📅 개발 일지: 2026-04-14 (학습의 확장과 개인화)

## 🎯 오늘의 마일스톤
**PRISM**의 사회 교과에 국한되었던 시스템을 전 교과(과학, 역사 등)로 확장하고, 사용자의 개별 관심사를 스토리에 더 깊게 투영.

## 🛠 구현 내용

### 1. 전 과목 인터랙티브 시스템 설계
- **데이터 추상화**: 특정 과목에 종속되지 않는 `mockData.ts` 구조로 전면 개편. 이제 과목 아이콘 하나로 사회(지리, 정치), 과학(물리, 생물), 역사(고대, 중세) 등 모든 단원 연동 가능.
- **Subject/Module Selection**: 대시보드 진입 전 과목과 단원을 선택하는 UI 컴포넌트 추가.

### 2. 관심사 기반 동적 시나리오 고도화
- **특수 선택지 [Special Interest]**: 사용자가 입력한 관심사(예: 우주, 코딩, 동물 등)가 스토리의 비유나 핵심 사건으로 등장하도록 프롬프트 강화.
- **직접 입력 방식 전환**: 기존 목록 선택 방식에서 사용자가 자유롭게 관심사를 텍스트로 입력할 수 있는 태그 시스템 기반 UI 도입.

### 3. 스토리 타임라인 (My Story Footprints)
- **발자취 추적**: 사용자가 지금까지 스토리 모드에서 내린 선택과 그 결과를 대시보드 하단에 세로형 타임라인 UI로 시각화.

## 📝 오늘의 성과
- 시스템의 범용성(Scalability) 확보: 새로운 교과 내용을 추가하는 데 드는 공수가 기존 대비 70% 감소.
- 사용자 몰입도 향상: "내가 좋아하는 '우주' 이야기가 사회 수업에 나와서 신기하다"는 사용자 피드백 반영 완료.
