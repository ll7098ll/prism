# 📅 개발 일지: 2026-04-15 (글로벌 진출 및 로컬라이제이션)

## 🎯 오늘의 마일스톤
**PRISM**의 전 세계 학습자를 위한 다국어(8개국) 지원 및 국가별 특화 교육 콘텐츠 생성 시스템 구축.

## 🛠 구현 내용

### 1. 국가/언어 마이크로 허브 구축
- **국가 선택 시스템**: 한국, 미국, 일본, 중국, 영국, 프랑스, 이탈리아, 독일 등 8개국 국기 버튼 및 현지어 표기 UI 도입.
- **실시간 i18n 엔진**: 로그인 화면에서 국가를 선택하면 모든 메뉴와 텍스트(UI/UX)가 해당 언어로 즉시 전환되는 동적 번역 레이어(`i18n.ts`) 구현.

### 2. AI 현지화 프롬프트 (Localized Logic)
- **맥락 인지 생성**: 단순히 직역하는 것이 아니라, 해당 국가의 역사적 사건, 과학적 사례, 문화적 배경을 바탕으로 스토리가 생성되도록 지침 고도화.
    - 예: 미국 학습자에게는 'NASA' 중심의 스토리, 한국 학습자에게는 '누리호' 중심의 스토리 생성.
- **플래그 이모지 통합**: 모든 페이지 상단에 해당 국가의 국기 이모지를 추가하여 현재 어떤 언어/국가의 환경에서 학습 중인지 직관적으로 인지.

### 3. 언어별 학습 DB 동기화
- **Firestore 연동**: 사용자가 선택한 언어(Country) 정보를 사용자 프로필 DB에 영구 저장하여, 이후 재접속 시에도 같은 환경을 유지하도록 설계.

- 전 세계 주요 국가의 초/중등 교육과정을 포괄할 수 있는 데이터 구조 완성.
