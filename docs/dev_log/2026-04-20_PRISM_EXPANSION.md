# [Phase 4] 글로벌 교육과정 확장 및 학교급 아키텍처 개편 (2026-04-20)

## 1. 개요
PRISM 프로젝트의 가장 큰 확장 단계로, 단순한 로컬라이제이션을 넘어 실제 전 세계의 교육과정을 수용할 수 있는 데이터 아키텍처로 진화했습니다. 8개국 지원, 288개 모듈 도입, 그리고 '학교급(School Level)' 기반의 개인화 엔진을 완성했습니다.

## 2. 주요 변경 사항 및 기술적 성과

### 2.1. 교육 데이터의 기하급수적 확장 (288 Modules)
- **국가 확장**: 기존 1개국에서 8개국(KR, US, JP, GB, FR, DE, IT, CN)으로 지식 베이스 확장.
- **계층 구조**: `국가(Country) -> 학교급(School Level) -> 과목(Subject) -> 모듈(Module)`의 4단계 계층 구조 확립.
- **모듈 규모**: 총 288개(8국 × 3급 × 3과목 × 4단원)의 실제 교육과정 기반 커리큘럼 구현.

### 2.2. 학교급(School Level) 기반 개인화 엔진 도입
- **난이도 체계 폐기**: 기존의 추상적인 'Beginner/Advanced' 대신, 실제 학년 수준인 '초등학교/중학교/고등학교' 체계로 전면 리팩터링.
- **지능형 프롬프트 가이던스**: `PromptFactory.ts`를 고도화하여 학교급별로 문장 길이(3-10문장), 어휘 수준, 교육적 피드백의 깊이를 동적으로 조절.
- **다국어 매핑**: 8개국 언어별로 상이한 학교급 명칭을 `i18n.ts`에서 완벽히 소화.

### 2.3. 아키텍처 리팩토링 및 타입 안전성 확보
- **그림자 로컬라이제이션**: `AppContext`에 `selectedSchoolLevel` 상태를 추가하여, 테마와 컨텐츠 필터링이 하나의 키로 동기화되도록 설계.
- **Zero-Type-Error**: `tsc --noEmit` 검증을 통해 프로젝트 전체의 타입 안정성을 확보하고, Any 타입을 제거하여 유지보수성 향상.

### 2.4. 사용자 경험(UX) 고도화 및 UI 리디자인
- **로그인 페르소나 강화**: 단순히 기능적인 로그인에서 벗어나, 'Hero Section'과 'Feature Highlights'를 포함한 몰입형 랜딩 페이지로 리뉴얼. `Particles` 효과를 적용하여 프리미엄 시각적 경험 제공.
- **프로필 지속성(Persistence)**: 기존 프로필 정보를 Firestore에서 실시간으로 호출하여 수정 시 자동으로 폼이 채워지도록(Pre-fill) 개선.
- **상시 접근성 확보**: 과목 선택 화면 헤더에 프로필 수정 전용 버튼을 배치하여, 로그인 이후에도 언제든지 학교급 및 관심사 변경이 가능하도록 설계.
- **라우팅 최적화**: 학교급 변경 후 즉시 `/subjects`로 리다이렉트하여 변경된 교육과정에 즉각 대응할 수 있도록 흐름 개선.

## 3. 기술적 의사결정 (ADR)
- **결정**: Firebase의 `level` 필드 값을 학교급 내부 키(`elementary`, `middle`, `high`)로 표준화.
- **이유**: 다국어 환경에서 문자열 비교 로직의 복잡도를 제거하고, 테마 및 프롬프트 계산 로직을 단일 진실원(Source of Truth)으로 관리하기 위함.

## 4. 향후 로드맵 반영
- 이 확장을 통해 PRISM은 글로벌 시장 어디서든 실제 학교 현장에 즉시 투입 가능한 수준의 커리큘럼 기반을 갖추게 되었습니다.
