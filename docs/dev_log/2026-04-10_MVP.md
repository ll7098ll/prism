# 📅 개발 일지: 2026-04-10 (MVP 탄생)

## 🎯 오늘무 마일스톤
**'PRISM — AI 기반 인터랙티브 교과서'**의 최소 기능 제품(MVP) 구현 및 Firebase 백엔드 연동.

## 🛠 구현 내용

### 1. 시스템 인프라 구축
- **Firebase 연동**: Google 로그인을 통한 사용자 인증 및 Firestore 데이터베이스 초기화.
- **AI 엔진 설정**: 
    - **텍스트**: `gemini-3.1-flash` (스토리텔링 및 문제 생성용)
    - **이미지**: `gemini-2.5-flash-image` (실시간 배경 생성용 - 프로젝트 코드네임 'Nano Banana')

### 2. 핵심 UI 컴포넌트 개발
- **Login**: Google 로그인 및 최초 진입점.
- **ProfileSetup**: 닉네임, 학습 수준(초급/중급/고급), 관심사를 수집하여 맞춤형 스토리 기반 마련.
- **Dashboard**: 학습 진행 상황을 관리하는 메인 허브.
- **Vocabulary**: 핵심 어휘를 플래시카드 형태로 학습하는 모듈.
- **StoryMode**: 사용자의 입력과 수준을 반영한 비주얼 노벨 스타일의 스토리 엔진.
- **Evaluation**: 학습 내용을 바탕으로 AI가 동적 퀴즈를 생성하고 채점하는 시스템.

### 3. 기술적 도전 및 해결
- **실시간 이미지 생성 지연**: AI 이미지 생성 시 발생하는 수 초간의 대기 시간을 로딩 인디케이터와 스켈레톤 UI를 통해 사용자 경험 저하 방지.
- **프롬프트 엔지니어링**: 학습자의 '수준'과 '관심사'가 스토리 텍스트에 자연스럽게 녹아들도록 JSON 포맷의 복합 프롬프트 설계.

## 📝 오늘의 성과
- 사회 교과(정부, 국회, 법원의 역할)를 미연시(비주얼 노벨) 형태로 학습할 수 있는 전체 루프 완성.
- 학습자 맞춤형 콘텐츠 생성 기능의 기술적 실현 가능성 확인.
